# 🤝 Contributing

This repository is mainly an automated DSA practice project, but improvements are welcome.

### Add a problem

Open `index.js` and add an object to the `problems` array:

```js
{
  title: "Your Problem",
  topic: "Arrays",
  difficulty: "Easy",
  description: "A one-line description of the challenge."
}
```

### Test your change

Run:

```bash
npm run plant
```

Then check `README.md`.

### Keep it clean

Prefer clear problem descriptions and standard DSA topics. 🌱
